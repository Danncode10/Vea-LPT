# Understanding the Self — thin direct coverage

Few standalone source files for this subject. When generating items, the
command should pull this subject's content from:
- `_EXAM_ENGINE/GEN_ED/_comprehensive/` (whole Gen-Ed reviewers)
- `_EXAM_ENGINE/_comprehensive_mixed/`
- `_EXAM_ENGINE/STYLE_BANK/gen_ed/` (real past-LET item phrasing)

Core topics: self from various perspectives (philosophy, sociology,
psychology, anthropology), the self in the modern/digital world, managing
and caring for the self, and the self as a future teacher.
