Pagbabagong Morpoponemiko
1. asimilasyon – dulot ng pagimpluwensiya ng mga katabing tunog nito
   (sing + tamis = sintamis, pang + dagat = pandagat)
2. pagpapalit – ponemang nagbabago o napapalitan sa pagbuo ng
   mga salita (d at r; dito – rito; ma + dapat – marapat)
3. paglilipat/metatesis – paglilipat ng posisyon ng mga ponema (y + in
   + akap = yinakap = niyakap; l + in + ayo = linayo = nilayo)
4. pagdaragdag – pagdagdag ng hulapi sa salita kahit mayroon nang
   hulapi (ka + totoo + han = katotohan + an = katotohanan)
5. pagkakaltas – pagkawala ng isang ponema o morpema na maari
   itong nasa unahan o sa gitna ng salita (bukas + an = bukasan
   = buksan; dala + hin = dalahin= dalhin)
