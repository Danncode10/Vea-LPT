# file_to_md

Extract text from any file or folder into `.md` files.

Accepts PDF, DOCX, DOC, PPTX, PPT. Run on a single file or an entire directory (recursive).

## Usage
```
/file_to_md <file-or-directory>
```

## Instructions

Run this exact command, replacing `$ARGUMENTS` with the path the user provided:

```bash
bash "/Users/lesterdannlopez/Desktop/VEA LPT/scripts/convert_to_md.sh" "$ARGUMENTS"
```

Then show the user the script output as-is.
